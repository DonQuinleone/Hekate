---
title: Upload requests
description: How someone outside the workspace sends files into a project without an account.
---

An **upload request** is a link for someone outside the workspace (a session engineer, a composer, a client's editor) to send files into one of a project's folders, or as a track's next version. They need no account, and the link lets them send files and nothing else: they never see what is already there.

- **Making one.** In a project's files, open the folder's menu and choose *Upload request…*. Give it a name, say what you want (they see it on the upload page), choose where files go (a folder, or *As the next version of* a track), how many files it takes (up to 100) and the day it closes (within 90 days). A password is optional, and so is an address to email the link to.
- **The link is shown once.** Copy it as it is made: only a fingerprint of it is kept. *New link* replaces it, and the old one stops working.
- **What arrives.** Files go straight into the folder, and you are told as each arrives. The same dialog lists your requests, what each has received and who sent it.
- **Sent to a track.** Each file arrives beside the track and becomes its next version once it has been processed (measured, for a recording), with the file as its one variation; two files make two versions, numbered as each is ready. Followers of the track and whoever made the request are told, and the track's workflows move on as for any version. The project's version checks still apply, and nobody can let a sender's file through: a file they refuse stays beside the track, and you are told why, to add it as a version yourself once it is put right. In a video project, the same works for a deliverable's next cut.
- **When it stops.** A request stops taking files once it has as many as it asked for, on the day it closes, or when you choose *Close the request*. It also stops if the project is archived or moved to another workspace.

Every request made and closed, every wrong password and every file sent is in the workspace's access log, under the name the sender gave.
