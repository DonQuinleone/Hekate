---
title: Upload requests
description: How someone outside the workspace sends files into a project without an account.
---

An **upload request** is a link for someone outside the workspace (a session engineer, a composer, a client's editor) to send files into one of a project's folders. They need no account, and the link lets them send files and nothing else: they never see what is already there.

- **Making one.** In a project's files, open the folder's menu and choose *Upload request…*. Give it a name, say what you want (they see it on the upload page), choose the folder, how many files it takes (up to 100) and the day it closes (within 90 days). A password is optional, and so is an address to email the link to.
- **The link is shown once.** Copy it as it is made: only a fingerprint of it is kept. *New link* replaces it, and the old one stops working.
- **What arrives.** Files go straight into the folder, and you are told as each arrives. The same dialog lists your requests, what each has received and who sent it.
- **When it stops.** A request stops taking files once it has as many as it asked for, on the day it closes, or when you choose *Close the request*. It also stops if the project is archived or moved to another workspace.

Every request made and closed, every wrong password and every file sent is in the workspace's access log, under the name the sender gave.
