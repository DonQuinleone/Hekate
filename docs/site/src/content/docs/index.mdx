Hekate is open-source (AGPL-3.0) and self-hosted: one app image, PostgreSQL and Caddy, on a machine you control. Everything it stores is encrypted with a key per file, media reaches a browser only through its protected delivery, and every key issued, page rendered and file downloaded is in the access log.

Music is first-class (tracks with versions and variations, bar numbers, score pages, session takes), and video and documents work just as well.

These pages are for the people who run Hekate and the people who use it: how to install and configure it, keep it backed up and up to date, what it does to protect unreleased material, and how reviews and guests work.
